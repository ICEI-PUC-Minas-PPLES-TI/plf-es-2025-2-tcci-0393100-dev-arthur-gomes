# Swagger to SDK

Este projeto tem o objetivo de automatizar a geração de clientes de acesso a serviços baseados no padrão de Transferência de Estado Representacional para aplicações de interface com o usuário, utilizando o TypeScript como linguagem principal e tomando como fonte de verdade, especificações em Swagger/OpenAPI.

## Instruções de utilização

Para poder utilizar o extensão, pode baixar diretamente na loja do VSCode pesquisando o seguinte ID na busca de extensões: SitaGomes.swagger-to-sdk

Também é possivel utilizar local, baixando o repositório, abrindo a pasta /Codigo com o seu VSCode, e clicando no botão de debug para poder abrir executar a extensão localmente.
